\# Olist Sales Dashboard



\## Project Overview

An e-commerce sales analysis project using Python, SQLite, SQL, and Power BI to explore order trends, payment methods, and product category performance.



\## Tools Used

\- Python and Pandas

\- SQLite and SQL

\- Power BI

\- CSV data exports



\## Dashboard

The Power BI report (`sales-dashboard-olist.pbix`) provides KPI summaries, monthly order trends, category analysis, and payment mix.



\## Key Findings

\- Total orders: 99,441

\- Delivered orders: 96,478

\- Delivered rate: 97.02%

\- Delivered payment value: BRL 15,422,461.77

\- Delivered payment AOV: approximately BRL 159.86



\## Data Notes

Raw source data and the local SQLite database are excluded from version control. Processed CSVs are used for dashboard visuals.



\## Reproducibility

Install dependencies from `requirements.txt`, prepare the source data locally, and run the Python scripts to load the database and export analysis datasets.
